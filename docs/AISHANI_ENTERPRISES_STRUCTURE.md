# Aishani Enterprises → DIMRI Studio Operating Structure

## Parent company
**Aishani Enterprises** is the parent/company umbrella. It owns and coordinates the ventures, brands, products and operating capabilities.

## Operating studio
**DIMRI Studio** is the AI-native operating studio under Aishani Enterprises. DIMRI AI / Company OS is the internal intelligence and orchestration layer, not a replacement for the parent company.

## Five operating pillars

### 1. DIMRI Media
Content creation, automated publishing and channel growth.
- YouTube channels and automated YouTube production/upload workflows
- Instagram content and publishing workflows
- Ghost Mode research → source verification → scripting → production → QA
- Shorts/Reels/long-form
- Thumbnails, titles, descriptions, SEO
- Channel analytics, audience analysis and experiments
- Monetization, sponsorship/brand opportunities
- Cross-platform repurposing

YouTube Data API can upload/manage videos and metadata; YouTube Analytics API can retrieve channel/content performance reports. Authorized OAuth access is required for modifying private account data, and new unverified upload projects have a private-upload restriction until the required audit/compliance process is completed. See official Google documentation.

### 2. DIMRI Digital Commerce
Digital products + blogging + affiliate + discovery traffic.
- E-books
- Digital stickers / sticker packs
- Printables
- Templates
- Prompt packs
- Wallpapers
- Digital art / creator assets
- Gumroad
- eBay
- Shopify
- Pinterest
- Blog / SEO / content clusters
- Affiliate programs and partner links
- Product feed / catalog operations
- Conversion tracking and revenue analytics

Pinterest's current API supports creating/managing Pins and boards and requires an authenticated app/token with the relevant boards/pins scopes.

### 3. DIMRI Apps
All consumer/business apps developed by the studio.
Current portfolio:
- VANI — building
- DermaVeda — planned
- YOU AI — planned

Every app gets a complete lifecycle:
Idea → PRD → UX/UI → Development → QA → Release → Store Ops → Analytics → Marketing → Support → Iteration.

Android monitoring should include Google Play release status, reviews, subscriptions/orders and quality data such as Vitals/crashes. The Play Developer Reporting API exposes metrics including crash rate, ANR rate and slow startup. Apple App Store Connect analytics provides downloads, sales, usage, sessions and crashes, with analytics/report APIs for connected workflows.

The DIMRI Apps dashboard should surface:
- crash/ANR alerts
- new bugs
- release/build status
- store reviews
- installs/active users
- retention
- subscriptions/revenue
- ASO opportunities
- campaign performance
- release regression detection
- recommended fixes and experiments

### 4. DIMRI Games
Dedicated game-development and publishing business.
Suggested sub-units:
- Game Ideation & Market Research
- Game Design / GDD
- Art & Animation
- Game Engineering
- Audio / Music / SFX
- QA / Device Testing
- Build & Release
- Store Publishing
- User Acquisition
- Monetization / IAP / Ads
- Analytics / Live Ops
- Community / Player Support
- Events / Content Updates
- IP / licensing workflow

Start with mobile games; expand later into PC/web/other platforms when product strategy justifies it.

### 5. DIMRI Products & Services
The existing 50-product/service portfolio lives here, grouped as:
1. Content & Creator (1–10)
2. Marketing & Growth (11–20)
3. Sales & CRM (21–30)
4. SMB / Industry Solutions (31–40)
5. Creative / Consumer (41–50)

These are commercial offers DIMRI Studio can sell directly or turn into SaaS/productized services.

## Shared company services
These are cross-pillar capabilities rather than a sixth commercial pillar:
- DIMRI CEO / Company Brain
- Persistent Memory
- Task Queue / Workflow Orchestration
- AI Workforce / Agent Factory
- Finance
- Operations
- Security / Privacy / Compliance
- Legal review support
- Customer Support / After-Sales
- Data / Analytics
- Credential & Integration Hub
- Founder Approval Engine

## Operating principle
One Company Brain, five business pillars, one shared data/permission layer.

Founder command:
**Aishani Enterprises → DIMRI Studio → Pillar → Department → Specialist Agent → Tool/API → QA → Approval (where required) → Result → Memory → Analytics → Next Action**

Consequential external actions remain founder-approval gated until the relevant connector and permission policy has been tested.
